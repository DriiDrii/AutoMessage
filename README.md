# AutoMessage

AutoMessage is a World of Warcraft Classic Era addon that automatically sends guild welcome and level-up congratulation messages.

## Features

- Sends welcome messages to new guild members
- Sends congratulation messages when guild members level up
- Supports configurable message channels and cooldown settings
- Opens a simple configuration interface with `/am` or `/automessage`

## Installation

1. Copy this addon folder into your World of Warcraft Classic Era `Interface/AddOns` directory.
2. Restart the game or reload your UI.
3. Use `/am` or `/automessage` to open the settings.

## Usage

- `/am` — open the AutoMessage configuration panel
- `/automessage` — same as above
